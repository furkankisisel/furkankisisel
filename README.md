## Hey, I'm Furkan 👋

I’m a Computer Engineering student at Ankara University and a mobile engineer focused on products that remain **fast, private, and useful in the real world** — including when the connection is weak or the problem gets complicated.

I enjoy taking an idea from architecture to a polished experience: native Android and Flutter apps, dependable offline data flows, secure real-time communication, and AI features that feel practical rather than decorative.
